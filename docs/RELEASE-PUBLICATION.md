# Stable publication of SSO Authentication 4.1.0.0

The operator approved first stable publication on 2026-10-31.
The production-ready release must be built from the accepted 4.1.0.0 source commit `45ffb412ff2c8174333eefdc63444341ab5038d5` without authentication-code changes. The release workflow validates code, ZIP, checksums, release assets, and the Jellyfin repository manifest before updating the catalog branch. Production Jellyfin installation is a separate manual step.
